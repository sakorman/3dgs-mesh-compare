# 共享正文带宽下的配对加载对照

2026-10-30。接续[每请求独立限速实验](PARALLEL-PAIR.md)，补充 SPZ 与 AP16 共用一份正文发送预算的验证。这里新增测量条件，候选加载算法仍为 `094b41d`，旧串行控制仍为 `6b2f875`；没有新的生产加载器或默认模型变更。

## 条件与结果

- Apple M5 / Chrome 156 / ANGLE Metal / WebGL2，Spark 2.4.0；pipes / office 保持 300,000 / 231,428 个高斯、完整 SH3、关闭 LoD、长边 768。照片、相机、训练/留出划分和模型文件不变。
- 每场景按串行／并行／并行／串行重复两组，共 16 个依次执行的样本；每次新建模型。热渲染器及 WASM、新 HTTP URL 键，不是整页或进程冷启动。共享限速不参与缓存命中路径，因此不重跑已完成的热缓存矩阵。
- 同一实验运行内的响应共享 **5MiB/s 正文上限**，64KiB 分块、每请求 40ms 服务器等待，按已就绪响应轮转；遇到背压跳过等待者，取消移除排队或已预约写入。空闲不积累额度，调度延迟后不突发补发。
- 保存每次服务端写入的共同原点时间和压缩正文字节数，逐样本验证合计字节、相邻写入间隔与总体时间下限。该调度器不是 TCP/HTTP2/QUIC、公网丢包或 RTT 模拟，也不含 HTTP 头与网卡实际流量。

下表为四个样本中位数，单位 ms。加载到候选发布为止；总等待继续到排序稳定后的绘制提交，不是 GPU 完成或屏幕呈现。各列独立取中位数。

| 场景／调度 | 加载 | 排序稳定等待 | 总等待 | 总等待最小—最大 |
| --- | ---: | ---: | ---: | ---: |
| pipes／旧串行 | 3239.35 | 83.75 | 3323.50 | 3313.90—3331.40 |
| pipes／新并行 | 3183.65 | 69.20 | 3252.75 | 3248.60—3257.10 |
| office／旧串行 | 2341.45 | 73.20 | 2414.65 | 2398.10—2422.90 |
| office／新并行 | 2286.85 | 69.60 | 2356.35 | 2348.30—2363.40 |

同一调度器下，并行的加载阶段减少 55.70 / 54.60ms，总等待减少 70.75 / 58.30ms（2.1% / 2.4%）。SPZ 初始化中位数分别为 180.00→172.30 / 143.60→138.40ms，解析器没有变化；总等待还包含排序与帧调度差异，不能将所有差额归因于网络或宣称解码加速。

**5MiB/s 是上限，不是实测速率。** 从首请求就绪到最后一次正文供给计算，pipes 串行／并行有效供给速率中位数为 4.139 / 4.224MiB/s，office 为 4.139 / 4.255MiB/s；全部样本范围 4.127–4.286MiB/s。计时器、背压及串行组第二个请求的等待都在其中。

前一实验的限速器按单响应累计期限调度，当前共享限速器还禁止补发突发，两者的时钟规则和采样批次也不同。因此保留旧报告，不把其 158 / 126ms 与这里的 71 / 58ms 差额全部解释为共享带宽的单因素影响，不比较两批绝对耗时来宣称版本退化。本批直接对照只说明：同一共享上限下仍有小幅收益，但并发并未消除传完整份模型的主要等待。

## 完整性、画面与取消

[原始 JSON](benchmarks/shared-pair-2026-10-30.json)包含 16 组阶段、每次正文写入、请求开始时间、输入摘要、36 次候选像素对照及 4 项取消/回退检查。每个成功样本均提供 13,071,355 / 9,335,099B，两份响应完整结束，实验期间文档可见。

36 次候选 RGBA 与既有控制全部一致，覆盖六个留出视角、每场景首视角 ±0.08rad 及各次首帧。六张参考图各取样一次并固定，旧／新调度的逐视角 PSNR、SSIM、MAE 完全相同；pipes 平均 16.268331dB / 0.731814，office 平均 18.962445dB / 0.839371。没有改变生产评分协议，也没有消除候选原有的量化误差。

两次取消都发生在**两份正文已经开始供给后**：SPZ 各 131,072B、AP16 各 1024B，随后连接关闭且未完成、没有请求 PLY 或创建候选。取消夹具让 AP16 在单独的停流端点等待，不将这 1024B 纳入限速性能样本。两次缺失 AP16 均取消 SPZ，再成功回退到原始 PLY，回退画面摘要一致。22 个模型各释放一次，未发现未处理异常；未测底层内存释放时刻或峰值。
