# 界面设计

工作台以双模型画面为中心，照片条承担视角导航；首页只保留模型查看；根据用户反馈，评测表和方法说明移至独立 benchmark.html 实验页。

- 配色：背景 #edf1f5、纸面 #ffffff、正文 #233140、次要文字 #697888、3DGS #246bb0、Mesh #ba7924。
- 字体：Avenir Next / PingFang SC，标题 30px、模型标题 14px、指标 13px，数字使用等宽数字特性。
- 左对齐；桌面并排、手机纵向两个等画幅模型。保留滚动，不强行将完整实验报告挤入一屏。
- 视觉重点只有真实重建画面。无宣传插图、渐变装饰、预填跑分。

首次方案复核：使用实际摄影胶片条代替通用 KPI 卡片，让实验输入和留出标记始终可见。

# 验证清单

- 两组真实照片、两个独立模型；原照片只在明确按下对照按钮时覆盖模型。
- 标定相机同位姿同画幅；照片切换、同步自由查看、重置、线框。
- AB/BA 串行性能测试、取消、尺寸改变/后台中断；无有效 GPU 扩展时不可用。
- 全部留出视角 PSNR/SSIM；排除留出照片参与 Mesh 几何和纹理生成。
- 报告导出、场景/分辨率切换后清空旧结果；模型错误可重试。
- 桌面和 390px 手机截图检查：画面不拉伸、按钮不裁切、无横向文档溢出。
- 异常探索：取消测试、重新选择场景、显示原照片后运行测试。
