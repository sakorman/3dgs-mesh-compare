# 界面结构

## 页面

- `index.html`：场景选择、双模型查看、拍摄视角与照片导航。
- `benchmark.html`：模型查看、性能采样、留出画质评测和 JSON 报告。

两侧模型共用相机位姿、投影参数和渲染尺寸。桌面并排显示，窄屏纵向排列。照片条标记训练与留出视角，选中照片后同时更新两侧相机。

## 查看操作

- 拍摄视角：使用照片对应的标定相机。
- 自由查看：共享相机及旋转中心，支持旋转、平移和缩放。
- 原照片：覆盖显示当前视角的去畸变照片。
- Mesh 线框：显示三角网格结构。
- 重置：恢复当前拍摄视角，关闭照片覆盖与线框。

性能和画质测试期间禁用查看操作；测试前恢复标定相机和标准渲染状态。切换场景或分辨率清空已有结果，切换拍摄视角清空性能结果。
