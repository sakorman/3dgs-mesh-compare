# 验证记录

数值测试覆盖 COLMAP→Three.js 的坐标系转换（含偏移主点）、奇异矩阵拒绝、SSIM/PSNR 解析值、GPU 不可用结果与 gzip 双重解压回归。

数据测试检查默认场景的文件哈希、PLY 高斯数量、GLB 完整性与有限顶点、三角数量、实际训练/留出集合、立体匹配两端不泄漏留出照片，以及深度断层不被三角片桥接。

浏览器操作使用真实模型。正式性能测试固定相机，数值只作为功能验证；本记录不把软件渲染或未隔离的桌面运行作为硬件结论。最后状态与运行证据在交付前更新。
